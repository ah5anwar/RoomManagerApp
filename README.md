# Room Manager — Android অ্যাপ (নেটিভ Kotlin + Jetpack Compose)

তোমার PHP/MySQL ব্যাকএন্ডের (RoomManager প্রজেক্ট) সাথে সরাসরি REST API দিয়ে কথা বলে এমন একটা সম্পূর্ণ নেটিভ Android অ্যাপ।

## ⚠️ প্রথমেই পড়ুন — খুব গুরুত্বপূর্ণ

এই প্রজেক্টটা **Android Studio বা Gradle ছাড়া কোনো এনভায়রনমেন্টে কম্পাইল করে যাচাই করা সম্ভব হয়নি** — যে সিস্টেমে এটা লেখা হয়েছে, সেখানে Android SDK বা Google-এর Maven রিপোজিটরি অ্যাক্সেসের সুযোগ ছিল না। তাই কোডটা প্যাটার্ন অনুযায়ী সঠিকভাবে, খুব সাবধানে হাতে-কলমে যাচাই করে লেখা হয়েছে (ব্রেস/প্যারেন ব্যালান্স, প্যাকেজ স্ট্রাকচার, ইম্পোর্ট — সব প্রোগ্রামেটিকভাবে চেক করা হয়েছে), কিন্তু **Android Studio-তে প্রথমবার ওপেন করে Gradle sync/build করাটাই আসল পরীক্ষা**। কোনো এরর পেলে সেটা আমাকে জানালে সাথে সাথে ঠিক করে দেব।

## প্রজেক্ট খোলার ধাপ

1. Android Studio (Hedgehog/Iguana বা তার পরের ভার্সন) দিয়ে এই `RoomManagerApp` ফোল্ডারটা **Open** করো
2. প্রথমবার খুললে Gradle sync শুরু হবে — ইন্টারনেট লাগবে (dependencies ডাউনলোড হবে)
3. যদি "Gradle wrapper" সংক্রান্ত কোনো prompt আসে (যেহেতু `gradle-wrapper.jar` বাইনারি ফাইলটা এখানে নেই), Android Studio-কে wrapper রিজেনারেট/ফিক্স করতে দাও, অথবা File → Settings → Gradle থেকে "Use Gradle from: 'wrapper'" এর বদলে নিজের ইনস্টল করা Gradle ব্যবহার করতে বলো

## সার্ভার URL সেট করা

`app/build.gradle.kts` ফাইলে খুঁজে বের করো:
```kotlin
buildConfigField("String", "BASE_URL", "\"https://room.creativesit.com/RoomManager/api/\"")
```
তোমার আসল ডোমেইন দিয়ে বদলে দাও (শেষে `/api/` থাকা আবশ্যক)। Gradle sync আবার করো।

## প্রজেক্ট স্ট্রাকচার

```
app/src/main/java/com/creativesit/roommanager/
├── MainActivity.kt              → অ্যাপের এন্ট্রি পয়েন্ট
├── RoomManagerApp.kt             → Application ক্লাস + AppContainer (সিম্পল DI)
├── data/
│   ├── model/                   → সব API রেসপন্সের ডেটা ক্লাস (User, Duty, Rent, Chat...)
│   ├── remote/                  → Retrofit ApiService, RetrofitClient, AuthInterceptor
│   ├── local/                   → SessionManager (DataStore দিয়ে টোকেন সংরক্ষণ)
│   └── repository/              → প্রতিটা ডোমেইনের জন্য Repository (Auth/User/Rent/Duty/...)
├── ui/
│   ├── theme/                   → ওয়েব অ্যাপের "হিসাবের খাতা" থিমের রঙ
│   ├── login/                   → লগইন স্ক্রিন
│   ├── navigation/              → Login <-> Dashboard নেভিগেশন
│   ├── dashboard/                → ড্রয়ার-নেভিগেশন শেল (রোল অনুযায়ী মেনু দেখায়)
│   ├── common/                   → শেয়ার্ড কম্পোনেন্ট (কার্ড, ব্যাজ, বাটন) ও ChatContent
│   ├── customer/                → গ্রাহকের স্ক্রিন (হোম, ভাড়া, ডিউটি, চ্যাট)
│   └── admin/                    → এডমিন/ম্যানেজারের স্ক্রিন (হোম, ইউজার, ভাড়া, ডিউটি শিডিউলার, নোটিফাই, চ্যাট, সেটিংস)
└── util/DateUtils.kt             → তারিখ, মাসের নাম, টাকার ফরম্যাট
```

## যা যা কাজ করে (ওয়েব অ্যাপের সাথে ফিচার-প্যারিটি)

- **লগইন** — user_code + password, টোকেন DataStore-এ সংরক্ষিত থাকে (অ্যাপ বন্ধ করলেও লগইন থাকে)
- **রোল-ভিত্তিক নেভিগেশন** — এডমিন সব দেখে, ম্যানেজার শুধু ভাড়া+৪টা ডিউটি, গ্রাহক শুধু নিজের পারমিশন অনুযায়ী
- **ইউজার ম্যানেজমেন্ট** — গ্রাহক/ম্যানেজার তৈরি, রোল পরিবর্তন, পারমিশন চেকবক্স
- **ভাড়া** — মাসিক সামারি, বকেয়ার তালিকা, পেমেন্ট আপডেট (WhatsApp নোটিফিকেশন ব্যাকএন্ড থেকেই যায়)
- **ডিউটি** — বাজার/রান্না/ময়লা/ক্লিন প্রতিটা আলাদা ট্যাব, মাসিক ক্যালেন্ডার-স্টাইল অ্যাসাইনমেন্ট (এডমিন/ম্যানেজার), "সম্পন্ন করলাম" বাটন (গ্রাহক)
- **নোটিফিকেশন** — কাস্টম মেসেজ পাঠানো + হিস্ট্রি
- **চ্যাট** — গ্রুপ চ্যাট (সবাই), প্রাইভেট মেসেজ (শুধু এডমিন), ছবি/অডিও ফাইল পাঠানো (গ্যালারি/ফাইল পিকার থেকে বেছে)
- **সেটিংস** — WhatsApp API কনফিগ, Webhook URL/Token (কপি বাটনসহ), নোটিফিকেশনের সময়, টাইমজোন

## জানা সীমাবদ্ধতা / ভবিষ্যতে যোগ করার মতো

- ভয়েস মেসেজ এখন **ফাইল পিকার** দিয়ে (গ্যালারি থেকে অডিও ফাইল বেছে) পাঠানো হয়, ইন-অ্যাপ রেকর্ডিং না — চাইলে `MediaRecorder` দিয়ে সরাসরি রেকর্ডিং যোগ করা যাবে
- পুশ নোটিফিকেশন (FCM) যোগ করা হয়নি — এখন সব ডেটা pull/polling ভিত্তিক (চ্যাট প্রতি ৪ সেকেন্ডে রিফ্রেশ হয়)
- অ্যাপ আইকন এখন সাধারণ ভেক্টর-ভিত্তিক প্লেসহোল্ডার (ওয়েব অ্যাপের রঙ/লোগো অনুসরণ করে) — চাইলে Android Studio-র Image Asset Studio দিয়ে আরও ভালো আইকন বানানো যাবে
